# pstack-anywhere

Portable fork of [pstack](https://github.com/cursor/plugins/tree/main/pstack) from the Cursor plugins repo.

This repo contains **only the pstack skills**. No other Cursor plugins, and no Benny automations.

Upstream author: [Lauren Tan (poteto)](https://x.com/poteto). License remains MIT.

## What’s here

44 skills under `skills/`, including `poteto-mode`, `setup-pstack`, the principle skills, and the situational ones (`how`, `why`, `unslop`, `tdd`, and the rest).

## Install

Clone this repo and point your agent at `skills/`:

```bash
git clone https://github.com/jnyross/pstack-anywhere.git
```

In Cursor you can also add this folder as a local plugin (`.cursor-plugin/plugin.json` is included).
